# Glossary

Language rule: code, identifiers, and code comments are in English. User-facing UI strings, issues, and specs are in Italian. When an issue says _carta_, the code says `Card`.

| Term (IT)                  | Identifier      | Meaning                                                                                                                                                                                                                                                                                                                                          |
| -------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| carta                      | `Card`          | The abstract card, identified by Scryfall's `oracleId`. Answers "which card". Never a specific printing.                                                                                                                                                                                                                                         |
| stampa                     | `Print`         | One specific printing of a `Card`: Scryfall id, set, collector number, language, release date, image status, image URL per face. Answers "which version".                                                                                                                                                                                        |
| faccia                     | `PrintFace`     | One printed face of a `Print`: its name and image URLs (small, normal, large). Single-faced prints have one face, double-faced prints two.                                                                                                                                                                                                       |
| riga                       | `DecklistLine`  | One entry of a decklist: original text, resolution status (`resolved` / `ambiguous` / `notFound`), `Card`, line language, quantity, and `Allocation`s. Language lives here, not on the allocation.                                                                                                                                               |
| candidati                  | `candidates`    | The cards an `ambiguous` `DecklistLine` could mean: several cards match its name exactly.                                                                                                                                                                                                                                                        |
| nome della faccia frontale | front-face name | The part of a multi-face card name before the `//` separator (`Delver of Secrets` in `Delver of Secrets // Insectile Aberration`). A line may name a card by its full name or its front-face name, ignoring case and spacing.                                                                                                                    |
| lingua                     | `Lang`          | The card language of a `DecklistLine` or a `Print`. Only `en` for now; ADR 0002 adds `it`.                                                                                                                                                                                                                                                       |
| allocazione                | `Allocation`    | A pair (`Print`, quantity) inside a `DecklistLine`. Explicit allocations never exceed the line quantity; the remainder implicitly goes to the default print.                                                                                                                                                                                     |
| stampa predefinita         | `defaultPrint`  | The most recent printable `Print` in the line language that is already released (release date on or before today; Scryfall lists previews earlier). Not printable: digital-only, art series, oversized, tokens, playtest cards, and `placeholder`/`missing` images. When an art series card shares the name, the card with a default print wins. |
| stampabile                 | printable       | A `Print` that can stand in for a playable paper card: everything not excluded by the `defaultPrint` rule.                                                                                                                                                                                                                                       |
| foglio                     | `Sheet`         | Layout options (page format, margins, spacing, crop marks, image quality) plus the lines to print.                                                                                                                                                                                                                                               |
| opzioni del foglio         | `SheetOptions`  | The layout options of a `Sheet`. Today: page format (A4) and image quality (JPG "large"); margins, spacing and crop marks come later.                                                                                                                                                                                                            |
| copia                      | `Copy`          | One printed instance of a line's card: one `Slot` per face. A line with quantity 4 prints 4 copies.                                                                                                                                                                                                                                              |
| slot                       | `Slot`          | One 63×88 mm cell of the sheet grid (3×3 per A4 page), holding one face image scaled uniformly to cover it, clipped to the card's outline: 63×88 mm with 3 mm rounded corners (ADR 0004). The faces of a copy sit in adjacent slots of the same row; a gap at the end of a row goes to the next single-faced copy, or stays empty.               |
| catalogo                   | `Catalog`       | The interface `core` uses to query cards and prints. `api` implements it on PostgreSQL; tests implement it in memory.                                                                                                                                                                                                                            |
| voce di catalogo           | `CatalogEntry`  | A `Card` with every `Print` the `Catalog` holds for it: what the catalog returns for a name lookup.                                                                                                                                                                                                                                              |
| stato immagine             | `imageStatus`   | Scryfall's `image_status`: `highres_scan`, `lowres`, `placeholder`, `missing`. Drives the language fallback.                                                                                                                                                                                                                                     |

_Avoid_: "card" for a printing (say `Print`), "variant" in code (a variant is a `Print` shown in the variant picker).
