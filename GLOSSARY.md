# Glossary

Language rule: code, identifiers, and code comments are in English. User-facing UI strings, issues, and specs are in Italian. When an issue says _carta_, the code says `Card`.

| Term (IT)                  | Identifier             | Meaning                                                                                                                                                                                                                                                    |
| -------------------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| carta                      | `Card`                 | The abstract card, identified by Scryfall's `oracleId`. Answers "which card". Never a specific printing.                                                                                                                                                   |
| stampa                     | `Print`                | One specific printing of a `Card`: Scryfall id, set, set name, collector number, language, printed name, release date, image status, faces. Answers "which version".                                                                                       |
| nome stampato              | `printedName`          | The name printed on a `Print`, in its language.                                                                                                                                                                                                            |
| faccia                     | `PrintFace`            | One printed face of a `Print`: its name, its artist and image URLs (small, normal, large, png). Single-faced prints have one face, double-faced prints two.                                                                                                |
| riga                       | `DecklistLine`         | One entry of a decklist: a `Card`, a quantity and a language, with the text it was written as.                                                                                                                                                             |
| riga scritta               | `WrittenCardLine`      | One line of the decklist text as the user typed it, with the `DecklistLine` it resolves to once the server has answered. Lines that name no card are not among them.                                                                                       |
| scelte della riga          | `LineChoices`          | What the user picked on one `DecklistLine` (its card among the `candidates`, its `AllocationChoice`), kept apart from what the server resolved it to.                                                                                                      |
| decklist salvata           | `SavedDecklist`        | The decklist text, its `LineChoices` and the `SheetOptions`, as the generator keeps them on the device for the next visit. The resolutions are not among them: the server is asked again.                                                                  |
| decklist in corso          | decklist under way     | The decklist the user is working on in the generator, from the device keeping it on entering or from its first recognised line, until a new decklist is started. The device keeps it as the `SavedDecklist` and no other.                                  |
| pannello della riga        | `LinePanel`            | The settings of one `DecklistLine`, shown when the user picks one of its tiles: in the `Inspector` on a wide screen, in a panel rising from the bottom on a phone. Not the `Sheet`.                                                                        |
| selettore delle varianti   | `PrintPicker`          | The grid inside the `LinePanel` where the user picks the `Print` a `DecklistLine` uses.                                                                                                                                                                    |
| ricerca della stampa       | `printQuery`           | What the user types in the `PrintPicker` to narrow its `Print`s.                                                                                                                                                                                           |
| selettore della sezione    | `SectionPicker`        | The choice above the search of an `AddCardTile` of the `DecklistSection` the card found joins.                                                                                                                                                             |
| ripartizione delle copie   | `CopyBreakdown`        | What the `LinePanel` shows of how a `DecklistLine`'s copies divide among the `Print`s they use, in either `Lang`, with the line's total.                                                                                                                   |
| tessera                    | `PrintTile`            | The copies of one `DecklistLine` that use the same `Print`, shown as one element of the card grid. The `unallocatedCopies` belong to the tile of the `defaultPrint`.                                                                                       |
| tessere sorelle            | sibling tiles          | The `PrintTile`s of the same `DecklistLine`: the `CardGrid` keeps them side by side and draws a link between them.                                                                                                                                         |
| gruppo di sorelle          | sibling group          | The sibling tiles of one `DecklistLine`, shown in one colour of the theme's sibling palette.                                                                                                                                                               |
| tessera a fuoco            | focused tile           | The element of the `CardGrid` the keyboard stands on, which its keys act on. Not the selected tile, whose `LinePanel` is open: one tile can be both.                                                                                                       |
| tessera senza immagine     | `ImagelessTile`        | The element of the `CardGrid` standing in for a `DecklistLine` with no print to show: not resolved yet, not found, ambiguous, or with no printable print.                                                                                                  |
| riga da sistemare          | line to fix            | A `DecklistLine` that will not print until the user fixes it: the `CardGrid` shows it as an `ImagelessTile`.                                                                                                                                               |
| guscio                     | `AppShell`             | The frame every area of the app lives in, with the navigation between the areas.                                                                                                                                                                           |
| area                       | `ShellArea`            | One part of the app with its own address, such as the generator at `/proxy`: the shell's navigation links to each one.                                                                                                                                     |
| area di lavoro             | `Workspace`            | The generator's screen-filling layout: the decklist text, the `CardGrid` and the `Inspector`, side by side on a wide screen, as `WorkspaceStep`s on a phone.                                                                                               |
| pagina di atterraggio      | `LandingPage`          | What the generator shows in place of the `Workspace` while no decklist is under way: it introduces the generator and starts a decklist.                                                                                                                    |
| decklist di esempio        | `EXAMPLE_DECKLIST`     | The decklist the `LandingPage` loads to show the generator at work, resolved as if written by hand, one of its lines then split over several prints.                                                                                                       |
| cosa sa fare               | `GeneratorFeatures`    | The part of the `LandingPage` that lists, in a few lines, what the generator can do.                                                                                                                                                                       |
| tutorial                   | `Tutorial`             | The part of the `LandingPage` that walks through the generator from the decklist to the PDF, one `TutorialStep` after another.                                                                                                                             |
| passo del tutorial         | `TutorialStep`         | One stage of the `Tutorial`: a sentence and a screenshot of the `Workspace` at that stage. Not a `WorkspaceStep`.                                                                                                                                          |
| passo                      | `WorkspaceStep`        | Where the user is in the `Workspace`: on a phone, the zone shown on the whole screen (the decklist, the cards, the sheet with its PDF button), picked from the bar at its foot. A wide screen shows every zone, so there only the `CentreView` follows it. |
| vista                      | `CentreView`           | What the centre of the `Workspace` shows: the card grid ("Carte") or the sheet ("Foglio"), picked from the tabs at its head on a wide screen, or as a `WorkspaceStep` on a phone.                                                                          |
| griglia delle carte        | `CardGrid`             | The zone of the `Workspace` that shows the decklist as `PrintTile`s, one `DecklistSection` after another, in the order of the decklist text within each.                                                                                                   |
| punto di arrivo            | `LineDestination`      | Where a line moved in the decklist text goes: a `DecklistSection`, and the line it is written beside or the end of that section. While a tile is dragged, the `CardGrid` shows it as a bar.                                                                |
| ispettore                  | `Inspector`            | The side zone of the `Workspace` that shows the settings of what is selected, or a summary of the decklist when nothing is.                                                                                                                                |
| pannello laterale          | `SidePanel`            | The decklist text or the `Inspector` at the side of the `Workspace` on a wide screen: the tab on its edge facing the centre folds it down to a strip that keeps its title, and dragging that edge sets its width.                                          |
| riepilogo                  | `DecklistSummary`      | What the `Inspector` shows while no tile is selected: how many cards, pages and lines to fix the decklist has, and its `defaultLang`.                                                                                                                      |
| sezione                    | `DecklistSection`      | A named part of a decklist, such as the main deck or the sideboard: a header line in the decklist text starts it, and the `CardGrid` shows it under its own title.                                                                                         |
| pila                       | `CopyPile`             | The copies of the card drawn behind the card of a `PrintTile` to show that it holds more than one copy.                                                                                                                                                    |
| carta ingrandita           | `zoomedCard`           | The card of a `PrintTile`, or of a `Print` in the `PrintPicker`, shown at reading size beside it while a pointer rests on it.                                                                                                                              |
| tessera di aggiunta        | `AddCardTile`          | The last element of each `DecklistSection` in the `CardGrid`, and its only element while the decklist has no card: it searches a card by name and adds it to its section, or to another one the user picks. Not a `PrintTile`.                             |
| candidati                  | `candidates`           | The cards an `ambiguous` `DecklistLine` could mean, each with its `defaultPrint`: several cards match its name exactly, or are about as close to a misspelled one.                                                                                         |
| scelta del candidato       | `applyCandidateChoice` | The card the user picked among an ambiguous `DecklistLine`'s `candidates`, by its oracle id. It is kept apart from the line, so it still applies when the line is resolved again.                                                                          |
| scelta delle allocazioni   | `AllocationChoice`     | The `Allocation`s the user set on a `DecklistLine` in the print picker, with the card they are prints of. Like the candidate choice it is kept apart from the line.                                                                                        |
| anteprima della riga       | `previewPrint`         | The `Print` a `DecklistLine`'s card image shows: the one its first `Copy` uses.                                                                                                                                                                            |
| nome della faccia frontale | front-face name        | The part of a multi-face card name before the `//` separator (`Delver of Secrets` in `Delver of Secrets // Insectile Aberration`).                                                                                                                         |
| chiave del nome            | name key               | A name in the form lookups compare, where case, spacing and accents do not matter.                                                                                                                                                                         |
| lingua                     | `Lang`                 | The language a `DecklistLine` asks for, or a `Print` is printed in.                                                                                                                                                                                        |
| lingua predefinita         | `defaultLang`          | The `Lang` every `DecklistLine` asks for; single copies can still go to `Print`s in another one. The user sets it on the generator page.                                                                                                                   |
| allocazione                | `Allocation`           | A pair (`Print`, quantity) inside a `DecklistLine`: how many of its copies the user put on that print.                                                                                                                                                     |
| copie non assegnate        | `unallocatedCopies`    | The copies of a `DecklistLine` no `Allocation` takes: they print with its `defaultPrint`.                                                                                                                                                                  |
| stampa predefinita         | `defaultPrint`         | The `Print` a `DecklistLine` uses when the user picks none.                                                                                                                                                                                                |
| pagina di stampe           | `PrintPage`            | One page of the printable `Print`s of a `Card` in one `Lang`, with how many there are in all and a cursor to the next page.                                                                                                                                |
| stampe per lingua          | `PrintCountsByLang`    | How many printable `Print`s a `Card` has in each `Lang`: what the `PrintPicker` shows beside each language.                                                                                                                                                |
| stampabile                 | printable              | A `Print` that can stand in for a playable paper card.                                                                                                                                                                                                     |
| immagine reale             | `hasRealImage`         | A `Print` image that is Scryfall's scan of the card, not a `placeholder` or a `missing` one.                                                                                                                                                               |
| foglio                     | `Sheet`                | The `SheetOptions` plus the lines to print.                                                                                                                                                                                                                |
| opzioni del foglio         | `SheetOptions`         | The layout options of a `Sheet`.                                                                                                                                                                                                                           |
| formato della pagina       | `PageFormat`           | The paper size a `Sheet` prints on.                                                                                                                                                                                                                        |
| qualità delle immagini     | `ImageQuality`         | Which Scryfall image a `Sheet` prints: the JPG "large" one, or the heavier PNG for maximum quality.                                                                                                                                                        |
| margine                    | `marginMm`             | The least white paper the `Sheet` leaves between the page edge and anything printed.                                                                                                                                                                       |
| spaziatura                 | `spacingMm`            | The paper the `Sheet` leaves between two neighbouring cards.                                                                                                                                                                                               |
| segni di taglio            | `CropMark`             | Short lines printed around the cards that show where to cut.                                                                                                                                                                                               |
| impaginazione              | `SheetLayout`          | Where everything of a `Sheet` goes on paper: page size, grid, each page's `PlacedSlot`s and the `CropMark`s. The PDF draws it and the page preview shows it.                                                                                               |
| slot posizionato           | `PlacedSlot`           | A `Slot` with the box the `SheetLayout` puts it in.                                                                                                                                                                                                        |
| anteprima della pagina     | `SheetPreview`         | One page of the `SheetLayout` drawn on screen as it will print. Not the `previewPrint` of a line.                                                                                                                                                          |
| copia                      | `Copy`                 | One printed instance of a line's card: one `Slot` per face. A line with quantity 4 prints 4 copies.                                                                                                                                                        |
| slot                       | `Slot`                 | One cell of the sheet grid, holding the image of one face of a `Copy`.                                                                                                                                                                                     |
| catalogo                   | `Catalog`              | The interface `core` uses to query cards and prints. `api` implements it on PostgreSQL; tests implement it in memory.                                                                                                                                      |
| voce di catalogo           | `CatalogEntry`         | A `Card` with every `Print` the `Catalog` holds for it: what the catalog returns for a name lookup.                                                                                                                                                        |
| stato immagine             | `imageStatus`          | Scryfall's `image_status`: `highres_scan`, `lowres`, `placeholder`, `missing`. Drives the language fallback.                                                                                                                                               |
| avviso sulla stampa        | `PrintWarning`         | Why the prints a `DecklistLine`'s copies use need the user's attention before printing.                                                                                                                                                                    |

_Avoid_: "card" for a printing (say `Print`), "variant" in code (a variant is a `Print` shown in the variant picker).
