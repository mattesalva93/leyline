# Security policy

## Reporting a vulnerability

Write to **mtgsuite@proton.me**. Please do not open a public issue for a vulnerability.

Say what you found, how to reproduce it and what it lets an attacker do. You get an answer as soon as the owner can read it; the project is run by one person in their spare time.

## Scope

The closed alpha: the app at its alpha address, behind the testers' credentials, and the code in this repository. The security baseline it meets is [ADR 0016](docs/adr/0016-security-baseline-for-the-alpha.md).

Card data and images come from [Scryfall](https://scryfall.com): report a problem on their side to them.
